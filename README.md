# BookPriorizer

An app to to handle book wishlists, priorize them, sort them by categories etc

## Developements

Pour l'instant, base simple, pas de notion d'authentification/de comptes

1. Listes d'envies
  - CRUD
  - priorisation des listes
2. Gestion des livres dans les listes
 - CRUD
 - Ajout de liens/description/références/commentaires
 - Pouvoir les marquer comme 'acheté'

## Technos

- [Bun](https://bun.com/docs)
- [ElysiaJS](https://elysiajs.com/quick-start.html)
- [AstroJS](https://docs.astro.build/en/getting-started/)
- [VueJS](https://vuejs.org/guide/quick-start.html)
- [TailwindCSS](https://tailwindcss.com/docs/installation/using-vite)
